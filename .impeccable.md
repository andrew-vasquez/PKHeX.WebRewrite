## Design Context

### Users
Power users editing Pokemon save files across desktop and mobile browsers. They use the app for detailed save manipulation, quick validation, and plugin-assisted workflows such as legality fixes or emulator handoff.

### Brand Personality
Calm, technical, trustworthy. The interface should feel precise and capable without becoming visually noisy or intimidating on smaller screens.

### Aesthetic Direction
Preserve the current Ant Design language and compact utility-first feel, but adapt it into a more intentional responsive system. Keep both light and dark themes from the start. Mobile layouts should prioritize one-handed use, readable grouped forms, and friction-free plugin workflows.

### Design Principles
1. Preserve information density without sacrificing clarity.
2. Adapt layouts for touch instead of shrinking desktop screens.
3. Keep controls predictable, restrained, and operationally focused.
4. Use a consistent internal component layer instead of library-driven visual drift.
5. Treat plugin workflows as first-class app behavior, not bolted-on admin screens.
